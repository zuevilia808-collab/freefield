# Freefield на компьютере

Программа, которая открывает профили Chrome (в каждом свой аккаунт Google) и сама делает фото и видео
в Google Flow, Dola, Arena и Vids. Сайт Freefield ей только передаёт задания и забирает готовое.

На компьютере она лежит в папке `Freefield` на рабочем столе:

| В репозитории | На компьютере | Что это |
|---|---|---|
| `pc/mcp/*.js`, `*.mjs` | `Freefield\mcp\` | сама программа (связь с сайтом на порту 5180, профили Chrome, сайты сервисов) |
| `pc/config.example.json` | `Freefield\config.json` | ваш конфиг (токен Hugging Face, Blender) — копия образца, заполняете сами |
| `pc/serve.js` | `Freefield\serve.js` | простой сервер страницы без генерации (не обязателен) |
| `pc/update.ps1`, `pc/update.cmd` | `Freefield\Обновить Freefield.cmd` | обновить программу из репозитория (см. ниже) |
| `index.html`, `css/`, `js/`, `img/`, `icons/` | `Freefield\app\` | страница Freefield — запасная копия (см. ниже) |

## Страница всегда новейшая
Программа отдаёт страницу (`http://127.0.0.1:5180` и по QR-коду на телефон) сразу с сайта на GitHub Pages — всегда последнюю
версию — и заодно кладёт её в `Freefield\app\`. Нет интернета — открывается копия из `app`. Кнопка «Обновить программу»
обновляет и `mcp`, и `app`. Проверить свои правки до публикации: запустить с `FREEFIELD_APP_LOCAL=1` — тогда только папка `app`.

## Запуск
- Вместе с Claude Desktop: программа запускается сама, пока Claude Desktop открыт.
- Или отдельно, без Claude: в папке `Freefield` выполнить `node mcp/hub-main.mjs`.
- Проверка: `http://127.0.0.1:5180` открывается.

## Персонаж → игровая 3D-модель (инструменты для Claude)
- **flow_image** — картинки Nano Banana во Flow: до 4 референсов (`image_paths`), размер `resolution` 1k / 2k / 4k
  (через меню Flow «Скачать», без пережатия), модель по умолчанию — новая **Nano Banana 2.1** (нет её в аккаунте — Nano Banana 2).
  Кредиты не тратит без `allow_credits=true`.
- **upscale_image** — увеличить ×2 / ×4: картинку Flow увеличивает сам Flow, остальные — Real-ESRGAN в Space на Hugging Face.
- **image_to_3d** — 3D-модель по картинке (или по видам спереди/сзади/слева/справа): сайт Hunyuan 3D (20 бесплатных в день),
  Spaces на Hugging Face (TRELLIS.2, Hunyuan3D-2.1), Tripo, Meshy. Файлы — в `Freefield\outputs\3d\<задание>\`.
  Платные кредиты не тратит без `allow_paid=true`. Формат glb / obj / fbx (FBX из GLB — через Blender, если он установлен).
- Все инструменты возвращают JSON: абсолютные пути файлов, ширину×высоту, модель, число полигонов, остаток бесплатного.
- Вход в сайты (Hunyuan 3D, Tripo, Meshy, huggingface.co) — один раз самому, в окне Chrome Freefield. Проверка: **portal_status**.

## В приложении: вкладка «3D» и «🔍 Увеличить»
- **3D** — последний раздел: картинка (кнопка 🧊 на картинке в галерее, свой файл, перетащить или
  Ctrl+V), виды сзади/слева/справа, где делать, качество, формат (GLB, OBJ, FBX), текстура, PBR. Задание уходит в эту
  программу (`/api/3d`), в галерее идёт живая карточка с этапом, готовая модель приходит карточкой «🧊 3D» (просмотр GLB,
  скачивание), фильтр галереи «🧊 3D».
- **🔍 Увеличить** — в просмотре картинки (`/api/upscale`), результат приходит обычной картинкой.
- **⟨/⟩** рядом с большой кнопкой каждой вкладки (и на кнопках «Что создаём») — какой промпт и запрос уйдёт; ничего не отправляется.

## Озвучка: «Эхо» — часть Freefield
«Эхо» (клон голоса на видеокарте, бесплатно) — часть Freefield: своего адреса у него в приложении нет. Программа Freefield
запускает «Эхо» **сама и скрыто, без окна терминала** — когда открыли вкладку «Озвучка» (и с телефона) или Claude озвучивает.
Ярлык «Эхо — озвучка» на рабочем столе запускать не нужно: Freefield берёт его (или файл запуска в папке `voice`, или путь
`echo_launch` в config.json). Код «Эхо» не меняем — Freefield работает с ним через его API.
- **Вкладка «Озвучка»** — «Эхо» прямо в Freefield, в его же виде: 1 «Видео с голосом» (загрузить ролик, выделить кусок),
  2 «Голос» (проверить текст, имя, эмоция, сохранить; «Мои голоса»), 3 «Текст озвучки» (эмоция, сила, язык, темп, варианты),
  справа — «Готовые озвучки» (слушать, ★, MP3 / WAV, удалить). Слева — голоса персонажей (имя персонажа = имя голоса).
- **С телефона**: на компьютере во вкладке «Озвучка» — «📱 На телефон», отсканировать QR-код телефоном (один раз, телефон в той
  же сети Wi-Fi). Freefield на телефоне (значок на экране) подключится к компьютеру сам; Chrome один раз спросит доступ к
  устройствам в локальной сети — разрешить. Не пустил — в «Озвучке» кнопка «Открыть «Озвучку» с компьютера».
  Чтение файлов по пути на диске с телефона закрыто.
- **В «Монтаже»** озвучки «Эхо» кладутся на звуковую дорожку («＋ Звук → 🎙 Озвучка «Эхо»»).
- **Для Claude**: `echo_voices`, `echo_speak` («озвучь голосом Паша радостно: …» → пути к MP3), `echo_clone_voice`
  (голос из отрезка видео или аудио по пути на диске). Порт «Эхо» — `ECHO_PORT` / `ECHO_URL`.

## В приложении: «Монтаж»
Таймлайн: дорожки **видео** (клипы друг за другом: тянуть края — обрезать и укоротить, ✂ — разрезать по бегунку, перетащить —
переставить, ◆ между клипами — переход «склейка / плавно / через чёрное»), **фото** поверх видео (весь кадр, центр, углы;
размер, видимость, появление), **титры**, **звук** (свой MP3 или любой звук, озвучка «Эхо»; громкость, нарастание, затухание).
Видео и фото — из галереи Freefield или «📱 С устройства» (галерея телефона, папка компьютера). Клавиши: пробел, S, Delete, ← →.
«Склеить видео» собирает MP4 прямо в браузере. «ИИ-монтажёр» — чат: сценарий по картинкам, инфографике, видео или промпту,
промпты для видео, автомонтаж.

## Конфиг: config.json (заполняете сами)
Токены и пароли Claude в чате не принимает. Токен Hugging Face (по желанию — чтобы 3D и апскейл шли на квоте вашего
аккаунта без окна Chrome) и путь к Blender вписываются в файл `Freefield\config.json` — образец `pc/config.example.json`.
Этот файл не загружайте в репозиторий.

## Обновить программу из репозитория
- **Один раз** (старая программа): на компьютере открыть PowerShell и вставить строку
  `irm https://raw.githubusercontent.com/zuevilia808-collab/freefield/main/pc/update.ps1 | iex` — скачает все файлы
  `pc/mcp`, прежние сложит в `Freefield\mcp\backup-<дата>`, рядом положит «Обновить Freefield.cmd».
- **Дальше** — двойной щелчок по «Обновить Freefield.cmd» или кнопка «⟳ Обновить программу» в приложении (если программа старая).
- После обновления — перезапустить программу: закрыть Claude Desktop полностью (значок у часов → «Выход») и открыть снова.
Страницу обновлять не нужно: `127.0.0.1:5180` сама берёт новейшую версию с GitHub.

## Для разработчика
- `mcp/dev/test-client.mjs` — проверить MCP-сервер так, как его вызывает Claude: `node mcp/dev/test-client.mjs`.
- `mcp/dev/portal-dev.mjs` — изучать страницы сайтов в окне Chrome Freefield (`open`, `shot`, `inspect`, `eval`).
- Папка `mcp/dev` к пользователям не скачивается: обновление берёт только файлы из самой `mcp`.
- Проверки приложения в браузере — папка `tests/` в корне репозитория (см. README).

## Не загружать в репозиторий (он публичный)
`config.json` — ваш токен Hugging Face; `.browser-profile*` — вход в ваши аккаунты Google; `mcp/.state.json`, `mcp/.batches.json`, `mcp/.lock-*` — ключ связи
и рабочее состояние; `outputs` — готовые фото и видео; `node_modules`.
