# Freefield — что умеет сейчас

AI-студия коротких роликов на бесплатных кредитах: персонаж → фото → сценарии → видео → монтаж → озвучка → 3D.
Работает в основном на компьютере: программа Freefield сама делает фото и видео в Google Flow, Dola, Arena и Vids
в окнах Chrome с аккаунтами пользователя; телефон подключается к ней по QR-коду.

## Приложение (сайт на GitHub Pages, PWA, APK)

Разделы — в порядке работы (на ПК колонкой слева, на телефоне сеткой):

| Раздел | Что делает |
|---|---|
| Персонажи | Герой роликов: развёртка, инфографика, кадры в локациях, голос (Flow-голос, образец, «Эхо»), язык речи. «🚀 Серия роликов» — одной кнопкой сценарии → кадры → видео. Экспорт и импорт персонажа файлом |
| Фото | «Создать инфографику», «Развёртка героя», «Персонаж в локации» — готовый промпт сразу в поле; Flow, Dola или Arena; несколько картинок со своими полями |
| Сценарии | ИИ (Claude или Gemini по ключу, или «ИИ в чате») пишет сценарии по инфографике, развёртке и кадрам — по эталонному промпту пользователя |
| Видео | До 10 сценариев: «Авто» раскладывает по Vids, Flow, Dola и Arena с учётом кредитов всех профилей Chrome; без компьютера — карточки для сайтов |
| Монтаж | Таймлайн: видео, фото поверх, титры, звук и озвучка «Эхо»; склейка в один MP4/WebM; «✦ ИИ-монтажёр» пишет сценарий и монтирует сам |
| Озвучка | «Эхо» внутри Freefield: голос из записи, сохранить, озвучить с эмоцией и вариантами; на ПК и телефоне через программу |
| 3D | 3D-модель по картинке (Hunyuan 3D, Hugging Face, Tripo, Meshy), GLB/OBJ/FBX; «🔍 Увеличить» в просмотре |

Сверху: **● Компьютер** (связь с программой), **Аккаунты** (профили Chrome и сайты с бесплатными кредитами),
**⚙ Настройки** (ключи Gemini и Claude, MCP, режим разработчика с кнопками ⟨/⟩, установка).
Пустая галерея — три шага: программа Freefield → аккаунты Google → персонаж.

## Программа на компьютере (`pc/mcp`)

- Связь с приложением на порту 5180 (`hub.js`): задания, готовые файлы, «Эхо», QR для телефона. Страницу отдаёт новейшую с GitHub Pages
  и хранит копию в `app` на случай без интернета.
- Профили Chrome — у каждого свои аккаунты и учёт кредитов; задания раздаются по всем сразу (`batch.js`, `portals.js`, `multilogin.js`).
- MCP для Claude (`server.js`):

| Инструменты | Что делают |
|---|---|
| `flow_image`, `flow_video`, `vids_video`, `dola_image`, `arena_video` | Фото и видео на сайтах под аккаунтами пользователя |
| `batch_generate` | До 10 сценариев: сам раскладывает по сайтам и профилям, при сбое — запасной сайт |
| `image_to_3d`, `upscale_image` | 3D-модель по картинке, увеличение ×2 / ×4 |
| `echo_voices`, `echo_speak`, `echo_clone_voice` | Озвучка через «Эхо» |
| `sync_sites`, `chat_photos`, `phone_tasks`, `phone_link`, `switch_account`, `portal_status` | Забрать готовое, фото из чата, телефон, аккаунты, вход и остаток кредитов |
| `free_credit_services`, `account_status`, `list_models`, `check_job` | Справка и долгие задачи |
| `generate_image`, `generate_video` | FLUX / AI Horde / Wan и платные модели Pollinations — в приложении их больше нет («Другие модели» и оплата убраны) |

- Кредиты не тратит без `allow_credits` / `allow_paid`. Пароли не вводит, проверки «я не робот» не обходит.
- Риск: у Flow и Dola нет официального API — лучше второй аккаунт Google.
