# Freefield — план

AI-студия для картинок и видео «как Higgsfield, только лучше»: бесплатные модели плюс платные с оплатой только за каждую генерацию.

## Что уже есть (прототип)

| Возможность | Как сделано |
|---|---|
| Бесплатные картинки | FLUX.1 [schnell] и [dev] на бесплатных GPU Hugging Face; AI Horde без дневного лимита (медленнее); автопереход на AI Horde, когда лимит FLUX закончился |
| Бесплатное видео | Wan 2.2 (картинка → видео, или текст → кадр FLUX → видео); Google Vids: 10 видео Veo 3.1 в месяц; Google Flow: 50 кредитов в день на Veo 3.1 |
| Кредиты на сайтах | 24 сервиса с бесплатными кредитами (Dola, Google Flow/Vids/Gemini/AI Studio, Kling, Dreamina, PixVerse, Qwen, Meta AI, Bing, ChatGPT, Leonardo, Krea, Recraft, Tensor.Art, SeaArt, Ideogram, Vidu, Pika, Firefly, OpenArt, Hailuo, Runway). У каждого: точные кредиты и на сколько картинок/видео их хватает. Генерация на их сайте под вашим аккаунтом, результат — в галерею. Данные в массиве `SERVICES` в `index.html` |
| Разделение | Каталог: «Бесплатно здесь» / «Кредиты на сайтах» / «Платные» — три отдельные группы и фильтры |
| Мои сервисы | Отметки «вход выполнен» (сам вход хранит браузер), «✨ кредиты ждут», счётчик за сегодня, быстрый переключатель сервисов на панели создания |
| Автоимпорт | Сайт открывается в окне рядом, промпт копируется; скачанный файл сам попадает в галерею (папка «Загрузки», Chrome/Edge на компьютере). На телефоне — «Вставить из буфера» или «Загрузить файл» |
| Установка | PWA: иконки, манифест, офлайн-кэш, кнопка 📲 с инструкциями для Android/iPhone и QR-кодом |
| Платные модели | 58 моделей Pollinations (Veo 3.1, Seedance 2, Nano Banana, GPT Image 2, FLUX.2, Ideogram, Grok…), живой каталог с ценами, цена на кнопке до запуска, счётчик трат, подтверждение дорогих генераций |
| Умный промпт | Gemini (бесплатный ключ Google) → Hugging Face → Pollinations → без ключей: перевод на английский |
| Интерфейс | 12 стилей, 12 движений камеры, форматы, галерея с поиском и просмотром, «Оживить», «Вариант», «Повторить»; десктоп + телефон |

## Лимиты бесплатных сервисов (честно)

- Hugging Face GPU: без входа 2 мин/день (несколько генераций), с бесплатным аккаунтом 5 мин/день.
- AI Horde: без лимита, очередь 1–10 минут, качество SDXL.
- Google Vids: 10 видео в месяц (720p, 8 с). API у Google Vids нет, поэтому генерация идёт на сайте Google.
- Google Flow: 50 кредитов в день (≈ 2–5 видео Veo Fast/Lite, плюс Nano Banana). API тоже нет — тот же способ, что с Vids.
- Gemini API: бесплатно только текст (для промптов); картинки и Veo через API у Google платные.

## Следующие шаги

### Этап 1 — надёжность бесплатного режима
- Кнопка «Войти через Hugging Face» (OAuth) вместо вставки токена.
- Больше бесплатных моделей с автоматическим переключением: Qwen-Image, Z-Image, LTX-Video для видео.
- Отмена генерации, повтор с паузой, понятные подсказки на каждую ошибку.
- Автосохранение результатов в папку `Freefield/outputs` на компьютере.

### Этап 2 — «лучше Higgsfield»
- Референсы: своё фото → картинка/видео (Nano Banana, GPT Image, FLUX Kontext, Seedance).
- Постоянный персонаж (аналог Soul ID): набор фото лица → одинаковый герой во всех генерациях.
- Начальный и конечный кадр для видео, продление ролика, видео со звуком.
- Бесплатный апскейл и удаление фона.
- Настоящие превью для стилей и движений камеры.
- Проекты/доски, избранное, история промптов.

### Этап 3 — телефон «как приложение»
- PWA: иконка на рабочем столе телефона, полноэкранный режим.
- Бесплатный хостинг (Cloudflare Pages или GitHub Pages), чтобы открывать с телефона где угодно, а не только по Wi-Fi.

2. Нужен ли доступ с телефона вне дома (тогда нужен хостинг — например, через ваш GitHub)?
3. Какие платные модели для вас главные — их выведу наверх каталога.

## Запуск
- Приложение — папка `app/` (её и выкладывать в интернет). Остальное — рабочие файлы.
- На компьютере: `node serve.js` → http://localhost:5173 (или двойной щелчок по `app/index.html`).
- С телефона в той же Wi-Fi сети: `node serve.js --lan` и открыть адрес, который он покажет.

## MCP-сервер для Claude (`mcp/`)
Claude сам генерирует картинки и видео и показывает их прямо в чате. Подключён к Claude Code и Claude Desktop
(после изменений сервера — перезапустить Claude Desktop / начать новую сессию Claude Code).

| Инструмент | Что делает |
|---|---|
| `flow_image` | Google Flow · Nano Banana 2 (по умолчанию, без кредитов) / 2 Lite / Pro, 1–4 варианта, ~10–20 с |
| `flow_video` | Google Flow · Veo 3.1 Lite (10 из 50 дневных кредитов) / Fast / Quality, Omni 1.1 Flash — 1–3 мин |
| `dola_image` | Dola · Seedream 5.0 (по умолчанию, без кредитов) / 4.5 — обычно 4 варианта, 1–3 мин; можно по фото-референсу |
| `arena_video` | Arena (arena.ai) · режим «битва»: один промпт → 2 видео от двух анонимных топ-моделей, бесплатно, 1–3 мин; можно оживить картинку |
| `batch_generate` | До 10 сценариев за раз: сам раскладывает по Flow / Dola / Arena и по всем профилям Chrome с учётом кредитов, всё запускается сразу, при сбое — запасной сайт. У сценария можно задать модель (`model`), длину (`seconds`: 10 с во Flow — Omni 1.1 Flash, 8 с — Veo 3.1 Lite) и фото-референс (`image_path`) |
| `chat_photos` | Фото, присланное в чат Claude Code, → файл в `outputs/refs` (его путь — в `image_path`) |
| `sync_sites` | Забрать в Freefield всё, что есть в проекте Flow и ещё не скачано (после каждого пакета запускается само) |
| `phone_link` | Связь с телефоном по Wi-Fi: QR-код → на телефоне открывается Freefield с компьютера (раздел «Для Клода») |
| `phone_tasks` | Пакеты с телефона и от Claude: статусы и файлы |
| `switch_account` | Сменить аккаунт на Flow (выбор аккаунта Google), Arena или Dola (выход → вход другим аккаунтом) |
| `portal_status` | Вход в Flow, Dola, Arena, остаток кредитов Flow и расход за сегодня |
| `generate_image` / `generate_video` | FLUX / AI Horde / Wan 2.2 (бесплатно) или платные модели Pollinations |
| `check_job` | Дождаться долгой генерации |
| `list_models`, `free_credit_services`, `account_status` | Справка: модели и цены, сайты с кредитами, ключи |

- Flow и Dola работают через **отдельный профиль Chrome** (`.browser-profile/`): пользователь один раз сам вошёл в Google и Dola, Freefield работает с сайтами как человек в видимом окне: промпты отправляет подряд, а результатов ждёт сразу нескольких (Flow — до 4 в одном проекте, Dola и Arena — до 2, каждая в своей вкладке). Пароли не вводит, проверки «я не робот» не обходит; если Flow пишет «подозрительная активность» — 30 минут не отправляет туда задания.
- **Профиль хранит вход в аккаунты — никому не передавать и не публиковать** (он в `.gitignore`).
- Риск: у Flow и Dola нет официального API; сайты могут посчитать автоматизацию нарушением правил и ограничить аккаунт. Лучше использовать второй Google-аккаунт.
- Ключи (необязательно) — в `env` сервера: `HF_TOKEN`, `POLLINATIONS_KEY`, `HORDE_KEY`.
- Результаты сохраняются в `outputs/<дата>/`; в чат — уменьшенные копии.
- Проверка: `node mcp/test-client.mjs --generate`, `node mcp/dev/test-tools.mjs portal_status`.
- Учёт: остаток кредитов Flow читается с сайта (панель аккаунта); Dola и Arena остаток не показывают — Freefield сам считает запросы
  и картинки/видео за день, а если сайт ответил «лимит исчерпан», до конца дня отправляет задания на другие сайты.
- Arena может публиковать промпты для исследований — личное туда не писать. Freefield на Arena не голосует.
- **Dola: видео** (Dreamina Seedance 2.0 Fast / 2.5 / 1.0, 5 или 10 с) тратит баллы Dola (2.0 Fast — 2 балла); остаток Dola называет в ответе,
  Freefield его запоминает. Фото реальных людей Dola не оживляет — тогда видео делается по тексту.
- **Фото-референс**: Flow — «ингредиент» (уже загруженное фото берётся из проекта, повторно не грузится), Arena — первый кадр,
  Dola — вложение в чат. Фото из чата Claude Code забирает `chat_photos` (Claude Code хранит переписку в `~/.claude/projects`).
- **Профили Chrome**: профиль N — отдельное окно Chrome (`.browser-profile-N`, порт 9333+N−1) со своими аккаунтами; у каждого свой учёт
  кредитов и входа (`.state.json` → `profiles`). Пакет раздаётся по всем профилям сразу. Новый профиль — кнопка «＋ Профиль Chrome».
- **Синхронизация** (`mcp/sync.js`): всё, что есть в проекте Flow и чего нет в Freefield, скачивается и попадает в галерею; дубли узнаются по содержимому.
- Код: `studio.js` — история, пакеты, связь с приложением (общий для Claude и `hub-main.mjs`), `batch.js` — план и запуск, `portals.js` — сайты,
  `refs.js` — фото-референсы. Запуск пакета без перезапуска Claude: `node mcp/dev/run-batch.mjs сценарии.json`.

### «Создать» → «Сценарии» (приложение)
- Переключатель «✦ Один промпт / 🎬 Сценарии → сервисы». Сверху — аккаунты по профилям Chrome: вход, баланс (кредиты Flow, баллы Dola, лимит Arena),
  «👤 Выйти из аккаунта» → «🔑 Войти» → «✅ Я вошёл», «↻ Проверить баланс», «＋ Профиль Chrome».
- У каждого сценария: видео/фото, «сервис + модель» (или ⚡ Авто) и подпись, куда он пойдёт; «📎 Фото-референс»; стиль из «Создать» добавляется ко всем.
- Большая кнопка внизу — «🚀 Запустить N сценариев» (на компьютере) или копия задания для Claude, если связи нет.
- В галерее у картинки — «📎 В сценарий». «🔄 Забрать всё из сервисов» — компьютер проверяет сайты и отдаёт всё за 2 дня.
- Связь с приложением держит `node mcp/hub-main.mjs` (или Freefield внутри Claude) — порт 5180, ключ в ссылке из `phone_link`.

### Раздел «Для Клода» в приложении и телефон
- Кнопка 🤖 «Для Клода»: три сервиса (Flow, Arena, Dola) с расходом за сегодня и кнопкой «Сменить аккаунт»,
  до 10 сценариев (видео/фото, сервис «Авто» или конкретный), формат, «✨ Улучшить промпты», план расхода кредитов.
- С телефона: на компьютере попросить Claude «подключи телефон к Freefield» (`phone_link`) → отсканировать QR →
  Freefield открывается с компьютера по Wi-Fi (`mcp/hub.js`, порт 5180, секретный ключ в ссылке) → «🚀 Запустить на компьютере».
  Готовые файлы сами приходят в галерею телефона; «📥 Забрать всё с компьютера» — все файлы из `outputs` за 2 дня.
- Без подключения (GitHub Pages, APK) — «📋 Скопировать задание для Claude» и вставить в чат.
- Работает, пока компьютер включён и открыт Claude Desktop. Windows при первом запуске спросит про доступ Node.js к сети — разрешить для частных сетей.

## Android-приложение (APK)
- Готовый файл: `Freefield.apk` (Android 7.0+). Собран через Capacitor 8 без Android Studio.
- Проект: папка `mobile/`. Пересборка после изменений: двойной щелчок по `mobile/build-apk.cmd`.
- Инструменты: Java 21 в `%USERPROFILE%\.jdks`, Android SDK в `%USERPROFILE%\AppData\Local\Android\Sdk`.
- Подпись — отладочный ключ (`%USERPROFILE%\.android\debug.keystore`): не удаляйте его, иначе новые версии не встанут поверх старой.
- В APK: сайты сервисов открываются во вкладке Chrome (вход общий с Chrome), «Скачать» сохраняет в «Документы/Freefield».

## Установка на телефон (PWA)
Приложение устанавливается как обычное: иконка на главном экране, запуск без адресной строки.
Телефоны разрешают полноценную установку только с адреса **https://**, поэтому папку `app/` нужно выложить на бесплатный хостинг
(GitHub Pages, Netlify или Cloudflare Pages). Дальше: открыть адрес на телефоне → кнопка 📲 вверху →
Android: «Установить»; iPhone (только Safari): «Поделиться» → «На экран „Домой“».
На компьютере в окне 📲 появится QR-код, чтобы быстро открыть адрес на телефоне.
