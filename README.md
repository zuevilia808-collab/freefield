# Freefield

AI-студия для коротких роликов на бесплатных кредитах: персонажи → фото → сценарии → видео → монтаж → озвучка → 3D.
Сайт: https://zuevilia808-collab.github.io/freefield/ (ставится как приложение, работает и без интернета).

## Как начать
1. **Программа Freefield на компьютере** — она делает фото и видео в Google Flow, Dola, Arena и Vids в окнах Chrome
   с вашими аккаунтами. Установка и запуск — [pc/README.md](pc/README.md); проверка: открывается `http://127.0.0.1:5180`.
2. **Аккаунты Google** — кнопка «Аккаунты» сверху: войдите в Flow, Dola и Arena в окне Chrome Freefield (один раз).
3. **Персонаж** — раздел «Персонажи»: развёртка, инфографика, кадры, голос. Дальше «🚀 Серия роликов» делает всё сама.

Телефон: на компьютере «● Компьютер» → «📱 На телефон» и QR-код. Ключи Gemini и Claude (для сценариев) — в «⚙ Настройках».
Подробно о возможностях — [pc/PLAN.md](pc/PLAN.md).

## Как устроено
- `index.html` — разметка, `css/app.css` — оформление, `js/*.js` — код по разделам (обычные скрипты, без сборки,
  подключаются по порядку: `core` → … → `init`). `sw.js` — офлайн-кэш (при добавлении файла — дописать его в `SHELL`
  и поднять версию `CACHE`).
- `pc/` — программа Freefield на компьютере: фото и видео на сайтах, связь с телефоном, «Эхо», MCP для Claude.
- `Freefield.apk` — приложение для Android со своей копией страницы внутри: обновляется только пересборкой
  (сайт и программа на компьютере обновляются сами).

## Проверки
Папка `tests/` — проверки в браузере (Playwright): все разделы и окна на ПК и телефоне, навигация, «Фото», окна выбора
файлов и ключи, «Озвучка» через настоящий хаб программы с макетом «Эхо», связка телефона по QR.
```
cd tests
npm install
npx playwright install chromium
npm test            # все; одну — node run.mjs voice
```
